# Employee Database App Project

## Hello. 

This is my first time using git to manage / commit files. Previously, I was adding them locally.

I have decided to pick back up this project and make it something usable by enterprises or companies.

The current phase is a lot more local based and is more so meant to showcase simple C++ skills which includes:
- String parsing
- I/O & fstream
- Local vector accessing, manipulation, & management with structs
- Switch-case for menu operation

After the creation of this phase, I plan to turn it into something more suitable for businesses. The program would include:
- Rule of 5
- Polymorhphism
- Cryptography & Employee Information security
- Chrono for real time time charts, as well as randomized scheduling
- SQL for data
